How to Install an EA in MT5, Step by Step

How to install an EA in MT5: MQL5 Market or .ex5 file, the Data Folder, Algo Trading button, XAUUSD lot checks and fixes for common EA errors.

An Expert Advisor (EA) is a program that runs inside MetaTrader 5 and can open, manage and close trades by its own rules. Installing one takes minutes, but small details decide whether it actually trades. This guide walks through both installation routes, the MQL5 Market and a downloaded .ex5 file, then covers the settings to check and the most common errors on XAUUSD.

Before you start: what you need

  • The MetaTrader 5 desktop terminal on Windows (or a Windows VPS). EAs do not run on the MT5 mobile apps or in the web terminal.
  • A trading account logged in, ideally a demo account first. Every EA should be tested on demo before it touches real money.
  • The EA file: an .ex5 file (compiled, ready to run) or an .mq5 file (source code that must be compiled first). A product bought on the MQL5 Market installs itself and you never handle a file.

MT4 EAs (.ex4/.mq4) do not run in MT5.

Method 1: install an EA from the MQL5 Market

  1. In MT5, open Tools → Options → Community and log in with your MQL5.com account. Purchases are tied to this account.
  2. Open the Market tab in the Toolbox (or buy on the MQL5 website while logged in to the same account).
  3. Find the product and click Buy, Rent or Free Demo. MT5 downloads and installs it automatically.
  4. Open the Navigator (Ctrl+N). The EA appears under Expert Advisors → Market.

Each Market purchase comes with a limited number of activations set by the seller. An activation is used each time the product is installed on a new computer or after major hardware or Windows changes, so install it on the machine or VPS where it will actually run. The free demo version only works in the Strategy Tester, which is the right place to try it first.

Method 2: install an .ex5 or .mq5 file manually

  1. In MT5 click File → Open Data Folder. Do not search Program Files: MT5 keeps your files in a separate data folder, and copying into the wrong place is the most common reason an EA "does not show up".
  2. Open MQL5 → Experts and paste the .ex5 file there. If the seller included a library or include file, put it in MQL5 → Libraries or MQL5 → Include as instructed.
  3. Back in MT5, right-click Expert Advisors in the Navigator and choose Refresh, or restart the terminal.
  4. For an .mq5 source file: double-click it in the Navigator to open MetaEditor, press F7 (Compile) and check that the log shows 0 errors. MetaEditor creates the .ex5 next to it.

Attach the EA to a chart

  1. Open the chart the EA was designed for, for example XAUUSD on the timeframe stated in its manual. An EA reads the chart it sits on, so the wrong timeframe changes its behaviour.
  2. Drag the EA from the Navigator onto the chart, or double-click it.
  3. On the Common tab, tick Allow Algo Trading. Only tick "Allow DLL imports" if the documentation says it is needed and you trust the source.
  4. On the Inputs tab, set risk, lot mode, magic number and any filters, then click OK.
  5. Make sure the Algo Trading button on the main toolbar is green. In older builds it was called AutoTrading.

When it is running, the EA name shows in the top-right corner of the chart with an active (blue) icon. A grey icon means algorithmic trading is disabled somewhere: on the toolbar, in the EA's Common tab, or in Tools → Options → Expert Advisors.

Check the settings before going live

Most EAs size positions either with a fixed lot or with a risk percentage of the balance. On gold the dollar value of a move is large, so check what the inputs mean in money terms. On a standard XAUUSD contract of 100 ounces per lot, a 1-dollar move is worth 100 USD per 1.00 lot, or 1 USD per 0.01 lot.

Worked example. A 5,000 USD demo account, risk input 1%, and the EA places its stop 12.50 dollars from entry. Money at risk is 50 USD. Lot = 50 ÷ (12.50 × 100) = 0.04 lot. If the first trade on demo opens at 0.40 instead, the input is probably being read as a fixed lot or the contract size differs, and you have found the problem before it cost anything. The XAUUSD lot size calculator gives the same figure, and the margin calculator shows how much free margin that position needs.

Contract sizes, minimum lots and lot steps differ between brokers and account types. Right-click the symbol in Market Watch, choose Specification, and compare contract size, volume min and volume step with what the EA expects. If the 1% sizing problem on small accounts is new to you, read the 1% risk rule with gold examples.

Common errors and what they mean

Open the Toolbox (Ctrl+T) and read the Experts and Journal tabs. Almost every problem leaves a message there.

Message or symptomLikely causeFix
"algo trading is disabled"Toolbar button off or Common tab untickedTurn on Algo Trading and re-open the EA properties
EA not in the NavigatorFile copied to the wrong folder, or it is an MT4 fileUse File → Open Data Folder → MQL5 → Experts, then Refresh
"invalid volume"Lot below the minimum or not a multiple of the lot stepCheck the symbol specification and the EA's lot inputs
"not enough money"Free margin too low for the lotLower risk or lot size; check leverage
"invalid stops"Stop or target closer than the broker's stops levelWider stop, or a broker with a lower stops level
"market closed"Weekend, holiday or daily break on goldNothing to fix; check the session times
No trades, no errorsSymbol suffix (XAUUSDm, XAUUSD.r), wrong timeframe, or entry conditions simply not metAttach to the broker's exact gold symbol and the documented timeframe; wait

"No trades yet" is often normal. A breakout EA such as the London Breakout EA may trade once a day or not at all on a quiet day, and a trend system like the Turtle Channel EA can wait days for a valid setup.

Keep it running

An EA only works while the terminal is open and connected. If you close MT5, shut down the computer or lose internet, it stops managing positions, including trailing stops and time exits; only stop loss and take profit orders already sent to the broker stay in place. That is why many traders run EAs on a VPS near their broker's server. After any restart, check the chart corner icon and the Journal tab to confirm the EA reloaded.

Honest risk note. Installing an EA correctly does not make it profitable. Test on a demo account for at least a few weeks, start live with the smallest size, use a stop loss on every trade, and avoid systems that rely on martingale or grids to recover losses. Past and backtested results do not guarantee future results.

Key takeaways

  • Market products install automatically; files go in File → Open Data Folder → MQL5 → Experts.
  • The EA trades only when Algo Trading is on in the toolbar and "Allow Algo Trading" is ticked for that chart.
  • On XAUUSD, 1.00 lot = 100 USD per 1-dollar move on a 100-ounce contract; check the EA's lot output on demo first.
  • The Experts and Journal tabs explain almost every "EA not trading" problem.

FAQ

Where do I put an EA file in MT5?

Click File → Open Data Folder in MT5, then open MQL5 → Experts and paste the .ex5 file there. Refresh the Navigator or restart MT5 and it appears under Expert Advisors.

Can I install an MT4 EA in MT5?

No. MT4 files (.ex4 and .mq4) do not run in MT5. You need a version written for MT5, or the source code rewritten in MQL5.

Why is my EA attached but not trading?

Check that the Algo Trading button is green, that Allow Algo Trading is ticked in the EA properties, and read the Experts tab. Wrong symbol suffix, wrong timeframe, too small a lot or simply no valid setup are the usual causes.

Can I run an EA on the MT5 mobile app?

No. The mobile apps can show trades opened by an EA, but the EA itself must run in the desktop terminal or on a VPS.

Do I need a VPS for an EA?

Not to install it, but an EA stops when your computer sleeps or disconnects, so a VPS is the usual choice for running it around the clock during the trading week.
