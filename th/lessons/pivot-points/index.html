Pivot Point คืออะไร

PP, R1/R2 และ S1/S2 คำนวณมาจากไหน และทำไมเทรดเดอร์จำนวนมากถึงจับตา

Pivot Point คือระดับราคาที่คำนวณจากราคาสูงสุด ราคาต่ำสุด และราคาปิดของเซสชันก่อนหน้า เพราะสูตรเปิดเผยและเรียบง่าย เทรดเดอร์นับพันคนจึงจับตาดูระดับเดียวกัน และนี่คือเหตุผลที่ราคามักมีปฏิกิริยาเมื่อเข้าใกล้ระดับเหล่านี้

สูตรคำนวณ

ใช้ ราคาสูงสุด (H), ราคาต่ำสุด (L) และ ราคาปิด (C) ของเซสชันก่อนหน้าที่ปิดไปแล้ว:

PP = (H + L + C) / 3
R1 = 2 × PP − L        S1 = 2 × PP − H
R2 = PP + (H − L)      S2 = PP − (H − L)

PP คือ Pivot กลาง R1 และ R2 คือแนวต้านที่อยู่เหนือขึ้นไป ส่วน S1 และ S2 คือแนวรับที่อยู่ด้านล่าง

ตัวอย่างการคำนวณ

สมมติเมื่อวานทองคำทำราคาสูงสุดที่ 4,240 ต่ำสุดที่ 4,180 และปิดที่ 4,220

ระดับวิธีคำนวณผลลัพธ์
PP(4,240 + 4,180 + 4,220) / 34,213.3
R12 × 4,213.3 − 4,1804,246.7
S12 × 4,213.3 − 4,2404,186.7
R24,213.3 + (4,240 − 4,180)4,273.3
S24,213.3 − (4,240 − 4,180)4,153.3

เทรดเดอร์อ่านระดับเหล่านี้อย่างไร

  • เมื่อราคาอยู่ เหนือ PP ฝั่งซื้อได้เปรียบในเซสชันนั้น เมื่ออยู่ ใต้ PP ฝั่งขายได้เปรียบ
  • R1 และ S1 คือจุดแรกที่ราคามักหยุดพักหรือกลับตัว
  • ระดับที่ถูกเบรกแล้ว ยืนได้เมื่อราคากลับมาทดสอบ (retest) มักสลับบทบาท: แนวต้านที่ถูกเบรกอาจกลายเป็นแนวรับ
  • R2 และ S2 มักถูกแตะในวันที่ราคาวิ่งแรง ซึ่งส่วนใหญ่มีข่าวเป็นตัวขับเคลื่อน
มองเป็นโซน ไม่ใช่เส้น ให้มองแต่ละระดับเป็นโซนเล็กๆ กว้างไม่กี่ดอลลาร์ ราคาแทบไม่เคยกลับตัวตรงทศนิยมเป๊ะๆ และโบรกเกอร์แต่ละเจ้านับวันตามเวลาเซิร์ฟเวอร์ที่ต่างกัน ระดับที่ได้จึงต่างกันเล็กน้อย

ข้อผิดพลาดที่พบบ่อย

  • ซื้อหรือขายทุกครั้งที่ราคาแตะระดับ โดยไม่รอสัญญาณยืนยัน
  • มองข้ามข่าวแรง (CPI, NFP, FOMC) ซึ่งอาจทำให้ราคาทะลุทุกระดับไปได้รวดเดียว
  • ใช้ Pivot สวนเทรนด์ที่ชัดเจน แทนที่จะใช้ไปตามเทรนด์

สรุปประเด็นสำคัญ

  • Pivot มาจากการคำนวณ ไม่ใช่การเดา ทุกคนจึงเห็นแผนที่เดียวกัน
  • PP บอกทิศทางที่ได้เปรียบ ส่วน R1/S1 คือโซนแรกที่ราคามักมีปฏิกิริยา
  • รอให้ราคาแสดงปฏิกิริยาที่ระดับนั้นก่อน แล้วค่อยตัดสินใจ
